User Login Feature

As a user, I want to login to the system with my username and password so that I can access my account.

Acceptance Criteria:
- User can login with valid credentials
- System displays error message for invalid credentials
- System prevents brute force attacks
- Login page loads in under 2 seconds

Functional Requirements:
The system shall authenticate users using username and password.
The system must validate that both username and password are provided.
The system shall redirect authenticated users to the dashboard.

Business Rules:
- Passwords must be at least 8 characters
- Accounts are locked after 3 failed login attempts
- Session timeout is 30 minutes

Constraints:
- Cannot use social login
- Must use secure password storage

Non-Functional Requirements:
- Login page must load within 2 seconds
- System must handle 1000 concurrent logins
